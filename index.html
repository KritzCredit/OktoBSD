The Power of UNIX.
Optimized for Multithreading.

OktoBSD is a modified version of FreeBSD 15 with tuned kernel internals. Featuring enhanced small-file performance on OpenZFS for AMD64, alongside full native support on Apple Silicon.

A university project with great potential!

Inspired by the best UNIX workstation designs. Bringing high performance, reliable graphics stacks, and kernel-level optimizations back to servers and dev machines.

Easy to install!

Automatic hardware detection installs only required drivers, instantly pairing the right graphics stack with your display architecture.

Isolation via Jails

Deploy lightweight isolated environments and microservices without the overhead of heavy virtualization via our integrated manager.

ZFS Optimization

Boosted SSD/NVMe read-write operations by up to 20% by stripping legacy mechanical disk operations directly from the FS pipeline.

pkg+ Package Manager

Direct access to the vast FreeBSD ports ecosystem with precompiled, architecture-specific binaries tuned for speed.

Kernel Security

Hardened Capsicum sandboxing, strict default audit controls, and minimal exposure footprint in clean baseline installations.

Easy Configuration

User-friendly utilities for networking, displays, and audio control without digging through complex rc.conf directives.

Explore the kernel source code

The OktoBSD kernel tree is open for contributions, testing, and independent compilation.
